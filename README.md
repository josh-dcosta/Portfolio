## 📖 About

This repository hosts my personal course portfolio for **CS 180**, showcasing my background, course objectives, and evidence of learning as I progress through the class. The site is deployed automatically to **GitHub Pages** on every push to `main`.

## ✨ Features

| | |
|---|---|
| 🎨 | Clean, modern, blue-themed design with subtle depth and motion |
| 📱 | Fully responsive layout for desktop, tablet, and mobile |
| 🧭 | Sticky navigation bar that stays pinned while scrolling |
| 🙋 | About Me section with profile photo and personal introduction |
| 🎯 | Dedicated section for each course outcome, with space for supporting evidence |
| 🤖 | Structured AI usage citation, disclosing tools and contributions |
| ⚡ | Zero dependencies — pure HTML & CSS, no build step required |

## 🛠️ Tech Stack

- **HTML5** — semantic page structure
- **CSS3** — custom styling, responsive layout, and animations
- **Google Fonts** — [Inter](https://fonts.google.com/specimen/Inter) & [Sora](https://fonts.google.com/specimen/Sora) for modern typography
- **GitHub Pages** — automated static site hosting & deployment

## 🚀 Running Locally

No build tools or dependencies required — just open the file directly:

```bash
git clone https://github.com/josh-dcosta/Portfolio.git
cd Portfolio
open index.html   # or double-click the file in your file explorer
```

## 🌐 Deployment

This site deploys automatically via **GitHub Pages** whenever changes are pushed to the `main` branch — no manual build or CI configuration required.

**Live site:** [josh-dcosta.github.io/Portfolio](https://josh-dcosta.github.io/Portfolio/)
